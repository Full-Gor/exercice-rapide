💎 Modèles Ruby

👤 User (Compte utilisateur)

# Créer une classe User = créer un modèle de compte utilisateur class User # attr_accessor = créer automatiquement les champs : nom, email, âge attr_accessor :name, :email, :age # initialize = constructeur = ce qui se passe quand on crée un utilisateur def initialize(name, email, age) @name = name # @name = variable privée de l'objet @email = email # @email = variable privée de l'objet @age = age # @age = variable privée de l'objet end # adult? = méthode qui retourne true/false (le ? indique une question) def adult? @age >= 18 # Si l'âge >= 18, retourne true end end # UTILISATION : # user = User.new("Alice", "alice@email.com", 25) # puts user.name # Affiche "Alice" # puts user.adult? # Affiche true

📁 Category (Catégorie du site)

# Créer une classe Category = créer un modèle de catégorie (comme "Électronique", "Mode") class Category # attr_accessor = créer automatiquement les champs : nom, description attr_accessor :name, :description # initialize = constructeur = ce qui se passe quand on crée une catégorie def initialize(name, description = "") @name = name # @name = variable privée de l'objet @description = description # @description = variable privée de l'objet end end # UTILISATION : # category = Category.new("Électronique", "Smartphones, ordinateurs...") # puts category.name # Affiche "Électronique" # puts category.description # Affiche "Smartphones, ordinateurs..."

🛍️ Article (Produit à vendre)

# Créer une classe Article = créer un modèle de produit (comme "iPhone 15", "T-shirt Nike") class Article # attr_accessor = créer automatiquement les champs : titre, contenu, auteur, catégorie attr_accessor :title, :content, :author, :category # initialize = constructeur = ce qui se passe quand on crée un produit def initialize(title, content, author, category = nil) @title = title # @title = variable privée de l'objet @content = content # @content = variable privée de l'objet @author = author # @author = variable privée de l'objet (qui vend) @category = category # @category = variable privée de l'objet (dans quelle catégorie) end # summary = méthode qui retourne un résumé du produit def summary "#{@title} par #{@author.name}" # Interpolation = mélanger texte et variables end end # UTILISATION : # article = Article.new("iPhone 15", "Nouveau smartphone", user, category) # puts article.title # Affiche "iPhone 15" # puts article.summary # Affiche "iPhone 15 par Alice"

🎯 Utilisation complète (Exemple concret)

# ÉTAPE 1 : Créer un utilisateur (Alice s'inscrit sur le site) user = User.new("Alice", "alice@example.com", 25) # ÉTAPE 2 : Créer une catégorie (le site a des catégories de produits) category = Category.new("Tech", "Articles tech") # ÉTAPE 3 : Alice vend un produit (créer un article) article = Article.new("Ruby Guide", "Contenu...", user, category) # ÉTAPE 4 : Utiliser les méthodes (afficher les informations) puts article.summary # Affiche "Ruby Guide par Alice" puts "Majeur: #{user.adult?}" # Affiche "Majeur: true" puts "Catégorie: #{article.category.name}" # Affiche "Catégorie: Tech" # RÉSULTAT : Alice (25 ans, majeure) vend un "Ruby Guide" dans la catégorie "Tech"
